Necesito que crees 6 clases de entidades C# dentro de la carpeta Entities/, siguiendo el namespace OnlyWear.Api.Entities. Estas son las entidades y sus relaciones:

1. Entities/Usuario.cs: Id (int), Nombre (string), Email (string), PasswordHash (string), Rol (string, default "Cliente"), FechaRegistro (DateTime, default UtcNow). Navegación: colección de Pedidos y colección de DisenoPersonalizado (Disenos).

2. Entities/Producto.cs: Id (int), Nombre (string), Descripcion (string), ImagenUrl (string), Activo (bool, default true). Navegación: colección de PrecioPorTalle (Precios) y colección de DetallePedido (DetallesPedido).

3. Entities/PrecioPorTalle.cs: Id (int), ProductoId (int, FK), Producto (navegación), Talle (string), Precio (decimal).

4. Entities/DisenoPersonalizado.cs: Id (int), UsuarioId (int, FK), Usuario (navegación), ImagenClienteUrl (string), PosicionX (float), PosicionY (float), Escala (float), TalleElegido (string). Navegación: colección de DetallePedido (DetallesPedido).

5. Entities/Pedido.cs: Id (int), UsuarioId (int, FK), Usuario (navegación), Fecha (DateTime, default UtcNow), Estado (string, default "pagado"), MetodoPago (string), MetodoEntrega (string), Total (decimal). Navegación: colección de DetallePedido (Detalles).

6. Entities/DetallePedido.cs: Id (int), PedidoId (int, FK, requerido), Pedido (navegación), ProductoId (int?, FK, nullable), Producto (navegación nullable), DisenoPersonalizadoId (int?, FK, nullable), DisenoPersonalizado (navegación nullable), Talle (string), Cantidad (int), PrecioUnitario (decimal).

Importante: ProductoId y DisenoPersonalizadoId en DetallePedido deben ser nullable (int?) porque un detalle de pedido corresponde a uno de los dos, nunca ambos ni ninguno obligatoriamente. PedidoId en cambio es obligatorio (no nullable).

Usá inicializadores de propiedad con string.Empty para strings y = null! para navegaciones requeridas no nulas, siguiendo las convenciones estándar de C# para entidades de Entity Framework Core.
