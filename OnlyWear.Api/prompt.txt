Necesito modificar el modelo de datos: DisenoPersonalizado debe referenciar un Producto base (la remera lisa sobre la que se arma el diseño), para poder sacar el precio según el talle elegido del PrecioPorTalle de ese producto.

1. En Entities/DisenoPersonalizado.cs, agregá:
   - ProductoBaseId (int, FK requerida, NO nullable)
   - ProductoBase (navegación a Producto, requerida)

2. En Entities/Producto.cs, agregá una colección de navegación DisenosBasados (los diseños personalizados que usan este producto como base).

3. En Data/OnlyWearDbContext.cs, configurá la relación DisenoPersonalizado → Producto (vía ProductoBaseId) con Fluent API, usando OnDelete(DeleteBehavior.Restrict) para no permitir borrar un producto que ya tiene diseños personalizados basados en él.

4. Generá una nueva migración de EF Core: dotnet ef migrations add AgregarProductoBaseADiseno

5. Aplicá la migración: dotnet ef database update

6. En Controllers/PedidosController.cs, corregí la lógica de cálculo de precioUnitario para detalles con disenoPersonalizadoId: en vez de poner 0, buscá el DisenoPersonalizado, tomá su ProductoBaseId, y buscá el PrecioPorTalle de ese producto que coincida con el Talle del detalle. Si no existe ese precio para ese talle, devolvé 400 BadRequest con un mensaje claro.

7. En Controllers/DisenosPersonalizadosController.cs, actualizá el endpoint POST api/disenos para que también reciba y guarde productoBaseId, y el DTO CrearDisenoRequest correspondiente en DTOs/.
